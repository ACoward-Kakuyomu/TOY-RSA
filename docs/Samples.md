# コマンドライン・サンプル

## 目的

実際のファイルで次を試すための補助 CLI を提供する。

- DES-CBC によるファイル暗号化・復号

## 実行ファイル

```text
des
```

Windows では `des.exe` となる。

## サブコマンド

```text
des encrypt KEY_HEX IV_HEX INPUT OUTPUT
des decrypt KEY_HEX IV_HEX INPUT OUTPUT
```

`KEY_HEX` と `IV_HEX` はそれぞれ正確に16桁の16進文字列とする。DES 鍵のパリティや弱鍵は教材として利用者が観察できるよう、DES-CBC サブコマンドでは自動修正・拒否しない。

## ファイル処理

DES-CBC はストリーミングファイル API を直接使用する。ファイル長 はC89 の `fseek` / `ftell` で取得できる範囲に制限される。

入力パスと出力パスが文字列として同一の場合は拒否する。処理が成功してから出力ファイルへ書き込むため、暗号検証失敗で既存出力を途中まで上書きしない。

## 終了状態

成功時は0、使用法誤りや処理失敗時は0以外を返す。診断は標準エラーへ表示し、鍵の秘密成分やセッション鍵は表示しない。

## テスト

CMake テストは一時ディレクトリで次を実行する。

- DES-CBC ファイル暗号化・復号と原文比較

## 現代の暗号技術から見た注意点

この CLI を追加しても、DES の現代的な弱点は変わらない。生成されるファイルを現代の機密情報保護に使用してはならない。
